Sales Analysis - SQL Project

About the Project
This project analyzes sales data of a retail business 
using MySQL. It covers product performance, customer 
behavior, monthly trends and city wise revenue.

Tools Used
- MySQL Workbench 8.0
- SQL (Structured Query Language)

Database Structure
- products  : Stores product details and pricing
- customers : Stores customer info and location
- orders    : Stores order dates linked to customers
- sales     : Stores quantity sold and revenue per order

Analysis Queries
- Query 1 : Total Revenue Generated
- Query 2 : Revenue by Product Category
- Query 3 : Top 5 Best Selling Products
- Query 4 : Monthly Sales Trend
- Query 5 : Top 5 Best Customers
- Query 6 : City wise Revenue

Key Insights
- Electronics is highest revenue generating category
- Laptop is best selling product by revenue
- Amit Singh is top customer by total spending
- Delhi leads in city wise revenue

Concepts Used
- CREATE TABLE
- INSERT data
- INNER JOIN
- Aggregate Functions (SUM, COUNT, AVG)
- GROUP BY and HAVING
- ORDER BY and LIMIT
- Subqueries
- CASE WHEN
